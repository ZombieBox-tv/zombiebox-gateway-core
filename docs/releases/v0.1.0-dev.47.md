# Core checkpoint v0.1.0-dev.47

The pinned go-librespot source can be staged with
`wrappers/spotify/patches/licensed-vorbis.patch`. The patch replaces the pinned
`xlab/vorbis-go` binding, which declares no license, with MIT-licensed
`jfreymuth/oggvorbis` v1.0.5 and `jfreymuth/vorbis` v1.0.2. Upstream checkouts
remain unchanged; both decoder repositories are cloned and commit-pinned as
references. The Spotify Dockerfile requires the staged patch marker and copies
both MIT licenses and the patch into the runtime image.

Host verification: the synthetic stereo fixture exercises Ogg metadata CRC,
decode, gain, one-second seek and close semantics; the modified Spotify image
builds and its CLI starts. Go vet/race, architecture and formatting checks pass.
No Spotify account, Android/Bionic workload or device acceptance is claimed.
The existing public Full dev.46 image is unchanged and remains under license
review; a new source-complete release is required for the patched binary.

Core dev.46's authenticated DASH alternate-audio test remains part of this
checkout. Product milestones remain open.
